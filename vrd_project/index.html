R@50 vs mR@50 — Training Configuration Comparison
Findings
Baseline (α=1.0)
Best R@50 at 68.88%. Class weights not needed for common predicates.
Focal + Class Weights
R@50 collapses to 23% — class weights over-penalise common predicates.
Label Smoothing
R@50 stuck at 59% — prevents sharp confidence on high-frequency predicates.
LSTM+VTransE* (partial)
mR@50 reaches 41.15% — BiLSTM context greatly benefits rare predicate recall. Not yet converged.
* LSTM+VTransE trained for 8 epochs only (batch_size=4). Full 30-epoch run expected to significantly improve R@50 while maintaining high mR@50.
