# data/

This directory is populated by the preprocessing scripts. Do not commit the generated files.

| File | Generated by | Description |
|------|-------------|-------------|
| `triplets_train.json` | `preprocess_vg.py` | Training set relationship triplets |
| `triplets_val.json`   | `preprocess_vg.py` | Validation set |
| `triplets_test.json`  | `preprocess_vg.py` | Test set |
| `pred_vocab.json`     | `preprocess_vg.py` | Ordered predicate vocabulary (index = class label) |
| `obj_vocab.json`      | `preprocess_vg.py` | All unique subject/object names |
| `llm_prior.json`      | `build_llm_prior_stub.py` | Commonsense prior scores per (subject, object) pair |

## Triplet format

Each entry in the triplet files looks like:
```json
{
  "image_id":    12345,
  "image_file":  "12345.jpg",
  "image_w":     800,
  "image_h":     600,
  "subject_name": "person",
  "predicate":    "holding",
  "object_name":  "cup",
  "subject_box":  [x1, y1, x2, y2],
  "object_box":   [x1, y1, x2, y2]
}
```

## LLM prior format

```json
{
  "person__cup":  {"holding": 0.72, "near": 0.12, ...},
  "dog__sofa":    {"sitting on": 0.65, ...},
  ...
}
```

Key = `"{subject}__{object}"` (double underscore, both lowercased).
